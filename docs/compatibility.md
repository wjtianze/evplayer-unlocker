# 兼容性与验证范围

## 已适配构建

工具优先按播放器组件的 SHA-256 选择精确的读取布局；但**不强制要求**组件指纹与已验证版本一致——其他构建会按运行中对象的特征自动识别并尝试导出（见下方“关于版本校验”）。

### EVPlayer 3.4.9.1（32 位播放器组件）

- 系统：Windows x64。
- 播放器：EVPlayer 3.4.9.1。
- 组件：`PlayerLibRender56_vs.dll`。
- SHA-256：`40285804d2aea4e911c282e6f421d5b90baa8c2338158ddcf8fc6d5a25fb58bb`。
- 数据模式：`Decryptor_V4A`，模式值 110；内层 MP4。

### EVPlayer 3.5.9（64 位播放器组件）

- 系统：Windows x64。
- 播放器：EVPlayer 3.5.9。
- 组件：`PlayerLibRender56_vs.dll`。
- SHA-256：`6a4a481d81ce606b959355265fa27a9db6274bf1978291d04d0c6c19a377a2c3`。
- 数据模式：`Decryptor_V4A`，模式值 110；内层 MP4。

安装包检查支持包含上述组件的 Inno Setup 安装包；实际验证过 Inno Setup 5.5.7 Unicode 格式。

## 关于版本校验

工具在读取运行中解码对象之前会先识别播放器组件：

- **指纹匹配已验证构建**：使用该构建验证过的 vtable 偏移做精确扫描，并据此选择 32 位或 64 位进程内的对象布局。
- **指纹未匹配**：不再直接拒绝，而是按对象特征自动识别——vtable 指向播放器组件内部、模式值为 110、会话指针与两处缓冲区指针均有效、主密钥为 32 字节、分块参数只由 `+ - * /` 组成。

自动识别依赖该构建的内部布局与已验证版本一致，因此**未验证的构建不保证成功**；失败时按提示先在原播放器中正常播放对应课程，然后重试。安装包检查仅用于版本诊断，不安装或启动播放器。

## 验证证据与边界

3.4.9.1 上，导出算法曾用于 34 个已授权视频，共 58,339.8 秒；所有输出通过 FFmpeg 7.1 的完整音视频解码，并记录了文件 SHA-256。3.5.9 上使用实际已授权课程录像（169,008,989 字节）验证：读取到运行中播放器的会话参数，首块解密后为 `ftyp`，导出 169,003,153 字节 MP4（2,160×1,080 H.264 视频 + AAC 单声道 32 kHz 音频，时长 2,823.5 秒），MP4 结构为 `ftyp/moov/free/mdat`，并用 FFmpeg 9.0.1 完整解码通过。公开项目不包含这些课程文件或授权数据。

源码回归测试使用公开的合成数据，覆盖跨分块还原、错误参数、中文路径、文件覆盖、取消、源文件变化和组件识别等。发行包另做自检与安装包解析验证。

图形界面有隐藏窗口构造检查。未把该检查等同于真实桌面的完整人工验收；最初课程验证中，用户中止了普通播放器界面操作，后续使用独立解码器验证。

## 限制

- 未验证构建的自动识别不保证成功：布局大改的版本仍可能取不到播放参数。
- 同版本号的其他构建、其他加密模式或非 MP4 内层格式不在已验证范围内。
- 仅有安装包、激活码或文件，不保证可以导出；原播放器必须已正常授权播放。
- 当前仅处理一个明确选定的 EVPlayer 进程。命令行可用 `--pid` 指定多个实例中的一个。
- 多个课程可能使用不同参数，需要分课程在原播放器中正常播放后再导出。
- 不覆盖已有输出；停止转换会清理本次未完成的临时文件，保留源文件及此前已完成的输出。
- 未选择 FFmpeg 时只证明容器结构已通过检查，不代表全片音视频解码已验证。
- 含长度为零的 MP4 顶层数据块或超出已验证范围的文件尾会被拒绝。
- 个别录像本身带重复时间戳，FFmpeg 会输出 muxer 时间戳警告；该警告不计为解码失败，其他解码错误仍会使验证失败。
