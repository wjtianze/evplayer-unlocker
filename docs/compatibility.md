# 兼容性与验证范围

## 已适配构建

- 系统：Windows x64。
- 播放器：EVPlayer 3.4.9.1，32 位播放器组件。
- 组件：`PlayerLibRender56_vs.dll`。
- SHA-256：`40285804d2aea4e911c282e6f421d5b90baa8c2338158ddcf8fc6d5a25fb58bb`。
- 数据模式：`Decryptor_V4A`，模式值 110；内层 MP4。
- 安装包：包含上述组件的 Inno Setup 安装包；实际验证过 Inno Setup 5.5.7 Unicode 格式。

工具在读取运行中解码对象之前核对组件指纹。未知指纹直接停止，不尝试套用地址。安装包检查仅用于版本诊断，不安装或启动播放器。

## 验证证据与边界

导出算法曾用于 34 个已授权视频，共 58,339.8 秒；所有输出通过 FFmpeg 7.1 的完整音视频解码，并记录了文件 SHA-256。公开项目不包含这些课程文件或授权数据。

源码回归测试使用公开的合成数据，覆盖跨分块还原、错误参数、中文路径、文件覆盖、取消、源文件变化和不支持的构建。发行包另做自检与安装包解析验证。

图形界面有隐藏窗口构造检查。未把该检查等同于真实桌面的完整人工验收；最初课程验证中，用户中止了普通播放器界面操作，后续使用独立解码器验证。

## 限制

- 同版本号的其他构建、其他加密模式或非 MP4 内层格式不在当前支持范围内。
- 仅有安装包、激活码或文件，不保证可以导出；原播放器必须已正常授权播放。
- 当前仅处理一个明确选定的 EVPlayer 进程。命令行可用 `--pid` 指定多个实例中的一个。
- 多个课程可能使用不同参数，需要分课程在原播放器中正常播放后再导出。
- 不覆盖已有输出；停止转换会清理本次未完成的临时文件，保留源文件及此前已完成的输出。
- 未选择 FFmpeg 时只证明容器结构已通过检查，不代表全片音视频解码已验证。
- 含长度为零的 MP4 顶层数据块或超出已验证范围的文件尾会被拒绝。
